# WesSciJo — Website Concepts

Three custom WordPress themes built for [The Wesleyan Science Journal](https://wesleyan.edu), a new hybrid peer-reviewed journal / science magazine at Wesleyan University. Built as Lead Web Designer to pitch three structurally distinct directions for the journal's launch site.

Each theme is a from-scratch WordPress build (custom `header.php` / `index.php` / `footer.php` / `functions.php` / `style.css`) — no page builder, no purchased theme. The brand palette (`#D72121` red, black, `#CB9A3B` gold) was measured directly from wesleyan.edu's live stylesheet rather than guessed, since the university's actual display/serif faces (Replica Pro, Copernicus) are commercially licensed and unavailable here; Libre Franklin, also present in Wesleyan's own font stack and free on Google Fonts, is used instead.

## The three concepts

| | Theme | Direction |
|---|---|---|
| 1 | `wessci-dark` | **Dark Laboratory** — near-black ground, red as a surgical accent, hover nav panels, monospaced metadata |
| 2 | `wessci-brutal` | **Editorial Brutalist** — red slabs, condensed display caps, a permanent index strip exposing every section without hovering |
| 3 | `wessci-broadsheet` | **Archival Broadsheet** — warm off-white, classical serif, centred masthead, a persistent left index rail with live article counts |

All three share the same structural requirements from the brief: article cards showing type + title + cover art, a prominent Current Issue, accessible Archives, and navigation organized around the journal's two divisions (Research & Reviews / News, Features & Perspectives) with article types nested beneath each.
